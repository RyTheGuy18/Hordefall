# Hordefall

Zombie survival shooter. Survive the night, solo, same-screen co-op, or online lobbies.

Play / install: https://rytheguy18.github.io/hordefall/

On iPhone: open in Safari, Share, Add to Home Screen.

## Controls
- Move: WASD / arrows / left stick / drag. Guns auto-aim; hold the mouse or use the right stick to aim.
- Build with run cash: **Q** barricade, **E** turret (controller **X / Y**, or the on-screen buttons).

## Adding music
Upload `music.mp3` (plays during runs) and/or `menu.mp3` (plays in menus) into this repo next to `index.html`. Volume is in Settings.
